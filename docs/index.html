Questions fréquentes

Autre question ? Ouvrez une Discussion GitHub ou écrivez à contact@sotechdi.com.

Comment obtenir ma clé API après abonnement ?
Après confirmation du paiement, vous recevez votre clé API par email. Ajoutez-la dans votre configuration MCP : "env": {"BRVM_API_KEY": "votre-clé"}. La limite de 25 appels/jour est automatiquement levée.
Quels modes de paiement sont acceptés ?
Orange Money, Moov Money, PayPal, et virement bancaire UEMOA. Contactez-nous à contact@sotechdi.com pour démarrer.
Le mode stdio (Claude Desktop local) est-il gratuit et illimité ?
Oui. Quand vous installez brvm-mcp localement via uvx, le serveur tourne sur votre machine et aucune limite ne s'applique. La limite de 25 appels/jour concerne uniquement les accès HTTP distants (Smithery, Railway).
Les données sont-elles en temps réel ?
La BRVM fonctionne par fixing unique (~10h45 GMT). Les données sont mises à jour après chaque séance avec un cache de 15 minutes. Vous obtenez toujours les données du dernier fixing officiel.
